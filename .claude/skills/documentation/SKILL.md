# Documentation

| File | Audience | Update when |
|---|---|---|
| `README.md` | Developers | Setup or scripts change |
| `AGENTS.md` | Agents and developers | Roles, workflow or rules change |
| `docs/BUSINESS_FACTS.md` | Everyone | The owner confirms or corrects a fact |
| `docs/OPEN_QUESTIONS.md` | Owner | A question is answered (move the answer to BUSINESS_FACTS) or a new gap appears |
| `docs/ARCHITECTURE.md` | Developers | A technical decision is made |
| `docs/DATA_MODEL.md` | Developers | Models change |
| `docs/ROADMAP.md` | Owner | A phase starts or ends |
| `docs/TEST_REPORT.md` | Owner, developers | End of each phase: what ran, results, Lighthouse numbers |
| `docs/DEPLOYMENT.md` | Operators | Phase 10 and any hosting change |
| `docs/ADMIN_GUIDE.md` | Staff | Admin features change (plain language, screenshots) |

## Style

Plain English, short sentences, present tense. Say what is true now, including what is not done or not
verified. Dates absolute (2026-10-25). No marketing language in technical docs.
